# beCafé UI

Sistema de diseño **Latte** (cristal translúcido cálido, claro y oscuro) y plantilla **SvelteKit 3 + Svelte 5 + Tailwind 4** para la PWA de control de stock de cápsulas del departamento.

```bash
npm install
npm run dev        # http://localhost:5173  ·  /componentes = catálogo de componentes
npm run check      # tipos + svelte-check
npm run build && node build   # producción (adapter-node)
```

Para que lo use una IA: entrégale **todo el contenido** y dile que empiece por [`AGENTS.md`](AGENTS.md).

Estructura: `tokens/` (tokens de diseño), `src/lib/components/` (componentes), `src/routes/` (pantallas de ejemplo), `docs/` (guías), `docs/spec/historias.md` (especificación).
