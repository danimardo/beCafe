# Avatar

Iniciales de la persona en círculo. Decorativo.

- Importar: `import { Avatar } from '#lib';`
- Archivo: `src/lib/components/ui/Avatar.svelte`
- Demo viva: ruta `/componentes#Avatar`

## Cuándo usarlo

Siempre junto al nombre en texto.

## Props

```ts
type Props = { name: string; size?: 'sm' | 'md'; class?: string };
```

## Accesibilidad

`aria-hidden`.
