# EmptyState

Estado vacío con icono, texto y acción.

- Importar: `import { EmptyState } from '#lib';`
- Archivo: `src/lib/components/ui/EmptyState.svelte`
- Demo viva: ruta `/componentes#EmptyState`

## Cuándo usarlo

Toda lista debe definir su estado vacío.

## Props

```ts
type Props = { title: string; description?: string; icon?: Snippet; action?: Snippet };
```

## Accesibilidad

Icono decorativo.
