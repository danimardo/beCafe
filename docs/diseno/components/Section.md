# Section

Bloque con título `h2` y acciones.

- Importar: `import { Section } from '#lib';`
- Archivo: `src/lib/components/layout/Section.svelte`
- Demo viva: ruta `/componentes#Section`

## Cuándo usarlo

Agrupa contenido dentro de una pantalla.

## Props

```ts
type Props = { title?: string; /** Acciones junto al título (p. ej. «Ver todo»). */ actions?: Snippet; class?: string; children: Snippet };
```

## Accesibilidad

Jerarquía de encabezados.
